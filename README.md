# TMW EPUB Library

Local-first Windows EPUB library browser with a private offline-capable Android companion. Source EPUBs are read-only.

[AGENTS.md](AGENTS.md) is the single guide for setup, builds, architecture, current features, storage/safety rules, implementation status, performance results and remaining work.

The unimplemented [dictionary improvements plan](dictionaryImprovementsAgents.md) remains separate. Original documentation and detailed historical evidence are preserved in [the documentation archive](docs/documentation-before-consolidation.zip); archived plans are not current instructions.
